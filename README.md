# BITEHUB 🍽️
### University Canteen Ordering System

BITEHUB is a web-based university canteen ordering system developed to make food ordering on campus easier and more convenient. Students can browse available food items, add items to their cart, and place orders for collection at the university canteen.

## ✨ Features

- User registration and login
- Browse food items and categories
- Search and filter menu items
- Shopping cart management
- Place food orders for campus pickup
- Pay at the canteen when collecting orders
- View personal order history and order status
- Admin dashboard for managing food items and orders
- Contact form for sending messages to the administration

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository into your XAMPP `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Create a MySQL database named `bitehub_db` using phpMyAdmin.
5. Import the project's database SQL file, if provided.
6. Check the database connection settings in `db.php`.
7. Open the project in your browser:

   `http://localhost/bitehub/`

## 🎯 Project Goal

The goal of BITEHUB is to provide a simple and convenient way for university students to order meals before visiting the canteen to collect and pay for their orders.
